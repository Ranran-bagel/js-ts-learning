# JS / TS 学习

2026-11-01 开始。

## 运行方法

```bash
node 01_basics/js_variables.js       # 运行 JS
npm run ts 01_basics/ts_variables.ts # 运行 TS
npm run check                        # 检查所有 .ts 文件的类型错误
```

## 目录

每一章都有 `js_<主题>.js` 和 `ts_<主题>.ts` 两个文件，对照着学。

| 章节 | 内容 |
| --- | --- |
| [01_basics](01_basics/) | 变量 const / let，基本类型 |
| [02_operators](02_operators/) | 运算符，类型转换 |
| [03_conditions](03_conditions/) | 条件分支 |
| [04_functions](04_functions/) | 函数，作用域，闭包 |
| [05_objects](05_objects/) | 对象，解构，type / interface |
| [06_arrays](06_arrays/) | 数组，循环，map / filter / reduce |
| [07_classes](07_classes/) | 类，继承 |
| [08_async](08_async/) | Promise，async / await |
| [09_modules](09_modules/) | import / export |
| [10_ts_advanced](10_ts_advanced/) | 泛型，联合类型，工具类型（仅 TS） |
